# **App Name**: System Vitals Dashboard

## Core Features:

- Temperature Gauge: Display real-time temperature readings using a gauge.
- Voltage Gauge: Display real-time voltage readings using a gauge.
- CPU Usage Gauge: Display real-time CPU usage as a percentage and current speed on a gauge.
- RAM Usage Gauge: Display real-time RAM usage as a percentage on a gauge, showing the amount free and the amount used.

## Style Guidelines:

- Primary color: Deep sky blue (#4169E1) for a clean and modern feel. The hue is evocative of computer systems and network infrastructure.
- Background color: Light grayish-blue (#D3DCEB), to provide contrast. The brightness is adjusted to fit the light color scheme, and it's desaturated enough to not be distracting.
- Accent color: Cyan (#00FFFF) for interactive elements. This will allow CTAs to pop without clashing, while remaining close to the main hue for visual consistency.
- Use a clean, sans-serif font for readability and a modern aesthetic.
- Use minimalist icons for system vitals, with subtle color cues.
- Gauges arranged in a clear, easily readable layout for quick monitoring.
- Smooth transitions for gauge updates and user interactions.
